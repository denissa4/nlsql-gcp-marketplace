Deploys NLSQL AI Agent into your AWS account on Amazon ECS with AWS Fargate from an AWS CloudFormation template: one task behind an Application Load Balancer, with an Amazon CloudFront HTTPS endpoint for the Microsoft Teams messaging endpoint. Answers come from Claude on Amazon Bedrock, called through the task's IAM role, grounded in documents in your own private, encrypted Amazon S3 bucket. In DocsAndSql mode (default) it also answers natural-language questions from your SQL database (SQL Server, MySQL, PostgreSQL, Amazon Redshift or Snowflake) with charts and tables; DocsOnly mode needs no database. Credentials are read from AWS Secrets Manager and never stored in the task definition. The linux/amd64 image runs as a non-root user and verifies your subscription with the AWS Marketplace Metering Service at start-up.
