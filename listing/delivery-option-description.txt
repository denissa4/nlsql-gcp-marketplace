Deploys NLSQL AI Employee into your AWS account on Amazon ECS with AWS Fargate from an AWS CloudFormation template: one task behind an Application Load Balancer that admits only the stack's Amazon CloudFront distribution, whose HTTPS endpoint is your Azure Bot's messaging endpoint and the Microsoft 365 sign-in's redirect URI. Answers come from Claude on Amazon Bedrock, called through the task's IAM role. Users' sign-ins, scheduled tasks, conversation history and files are kept in two Amazon DynamoDB tables and two Amazon S3 buckets in your account, retained when the stack is deleted. Your bot's client secret is read from AWS Secrets Manager, and the stack generates its own encryption key there; neither is stored in the task definition. The linux/amd64 image runs as a non-root user and verifies your subscription with the AWS Marketplace Metering Service before it serves any request. Optional, with your own Google Gemini API key: the browser agent and image reading.
