NLSQL AI Employee is an AI assistant for Microsoft Teams that runs in your AWS account, using Claude on Amazon Bedrock. After a one-time Microsoft 365 sign-in, each user asks it in plain language to read, write and send email, manage the calendar and work with OneDrive files. It reads documents sent in chat, remembers what it is asked to, runs tasks on a schedule, sends a daily morning briefing and alerts users to important email and upcoming meetings. Other Azure Bot Service channels, such as Web Chat and Direct Line, work too, without the Microsoft 365 features. It deploys from one AWS CloudFormation template onto Amazon ECS with AWS Fargate, calls AWS only through the task's IAM role, and keeps your users' data in your own Amazon DynamoDB tables and S3 buckets.

This product extends the functionality of Microsoft Teams and without it, this product has very limited utility. Please note that Microsoft Teams might require its own license for full functionality with this listing.
