Version title: 1.0.0 - First release on Amazon ECS

Release notes:

Critical
- None. This is the first release of NLSQL AI Agent on AWS Marketplace; there is nothing to upgrade from.

Important
- Deploys on Amazon ECS with AWS Fargate from an AWS CloudFormation template: one task, an Application Load Balancer that only accepts requests from the stack's own CloudFront distribution, and an HTTPS messaging endpoint for Microsoft Teams.
- Two modes: DocsAndSql (default) answers from your documents and, through NLSQL, from your SQL database (SQL Server, MySQL, PostgreSQL, Amazon Redshift, Snowflake) with charts and tables; DocsOnly answers from documents alone.
- Answers are generated by Claude on Amazon Bedrock through global inference profiles, called with the task's IAM role. No AWS access keys are used or accepted. Choose Claude Opus 5 (default), Opus 5.5, Opus 4.8, Sonnet 5, Sonnet 5.5, Sonnet 4.6 or Haiku 4.5. Each model must be enabled in Amazon Bedrock in your account before use.
- Documents are read from a private, encrypted Amazon S3 bucket the stack creates (or one you name) and indexed at start-up. The embedding model is part of the image, so nothing is downloaded at run time. After adding documents, start a new deployment of the service to re-index.
- Teams turns are acknowledged immediately and answered as soon as they are ready, so long questions do not time out. Files sent to the bot in a personal chat can be asked about directly.
- Credentials (bot client secret, NLSQL API token, database password) are read from one AWS Secrets Manager secret, optionally encrypted with your own AWS KMS key, and are never written to the task definition or the logs.
- The container runs as a non-root user on port 8080, on a supported Debian 13 and Python 3.13 base. The subscription is verified with the AWS Marketplace Metering Service before the task accepts any traffic; /health returns 503 until then and /ready reports when documents are indexed.
- Charts and CSV exports are served from unguessable links and deleted after 24 hours.

Optional
- LanguageModelContext sets your own system prompt for document answers.
- Streaming shows document answers in Teams as they are generated.
- TaskCpu, TaskMemory and EphemeralStorage size the task; the defaults (4 vCPU, 8 GB, 40 GiB) suit most document sets.
